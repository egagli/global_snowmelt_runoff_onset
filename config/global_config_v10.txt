# unchanged (edges snap to multiples of `resolution`), so pixel centers never move
# and v9 pixel (i,j) == v10 pixel (i+4096, j), v9 tile (r,c) == v10 tile (r+2,c).
#   top    81.099 -> 84.048  (realized 84.0485640): +4096 rows = +2 whole tile rows,
#          covering all land on Earth (northernmost is Kaffeklubben Island, 83.67N).
#   bottom -59.999 -> -63.4074 (realized -63.4075834): latitude is now an exact
#          multiple of the 2048 tile/shard size (100 tile rows, no partial row in y),
#          so any future southward extension is a clean append. Reaches South Orkney,
#          the South Shetlands and the Antarctic Peninsula tip.
# Both values are snap-sensitive: from_bbox expands OUTWARD to the lattice, so
