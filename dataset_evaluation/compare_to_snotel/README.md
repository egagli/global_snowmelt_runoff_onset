# Comparison to SNOTEL / CCSS — manuscript Fig. A1 provenance

**Status: retained for manuscript provenance only.** The network-wide SNOTEL/CCSS
evaluation this folder once held was superseded by
[`../compare_to_all_public_snow_pillows/`](../compare_to_all_public_snow_pillows/README.md)
(~1,500 stations across 10 networks, versioned outputs, persisted result tables).
What remains here are the notebooks behind the **published (v9) Fig. A1** and its
companion low-FCF investigation, plus the notebook that builds their input dataset.

The superseded half — `all_station_comparison_analysis.ipynb`,
`environmental_conditions_analysis.ipynb`, `inspect_single_station.ipynb`,
`station_plots.py`, and the figures they produced — was **archived to git history and
deleted on 2026-08-13**. Nothing is lost; recover any of it with:

```bash
git checkout archive/compare-to-snotel -- dataset_evaluation/compare_to_snotel/
# or read one file without restoring it:
git show archive/compare-to-snotel:dataset_evaluation/compare_to_snotel/all_station_comparison_analysis.ipynb > /tmp/x.ipynb
```

Note the archive does **not** include `comparison_datasets/` (gitignored); a restored
notebook needs its input NetCDF regenerated by
`create_all_station_comparison_dataset.ipynb`.

## What the analysis did

For each station, the SAR-derived onset (minimum C-band VV backscatter within the
MODIS-constrained melt search window) is compared to the snow-pillow-derived onset
(last day SWE ≥ 95 % of the water-year maximum), sweeping buffer radii (100–1000 m)
and forest-cover-fraction thresholds (10–100 %) to characterize sensitivity. Coverage
is ~969 [SNOTEL](https://www.nrcs.usda.gov/wps/portal/wcc/home/snowClimateMonitoring/snowpack/snowpackNationalMaps/)
and CCSS stations across the western US, water years 2015–2024.

## Notebooks

### `supplemental_figure_methodology.ipynb` — writes manuscript Fig. A1

Produces `figures/v9/high_swe_low_swe_backscatter_comparison_846_CA_SNTL_2017_2021.png`
(846_CA_SNTL Virginia Lakes Ridge, high-SWE WY2017 vs. low-SWE WY2021; the `savefig`
call is commented "manuscript figure A1"). Selects one station with clear SAR–SWE
agreement and one with an ambiguous signal, then builds a multi-panel figure —
filtered SWE with the 95 % threshold marker, per-orbit SAR backscatter with detected
minimum, MODIS snow dates, onset offsets across water years — plus a satellite context
map (`context_visual_fcf_dem_<station>.png`) showing footprint, forest cover and terrain.

The v10 successor is
[`../compare_to_all_public_snow_pillows/6_station_high_swe_low_swe_comparison.ipynb`](../compare_to_all_public_snow_pillows/6_station_high_swe_low_swe_comparison.ipynb),
rebuilt on that framework's zarrs with the same styling; it reproduces the v9
onsets/offsets exactly. Both columns are shown side by side in
[`../../docs/results_and_figures.md`](../../docs/results_and_figures.md).

### `supplemental_figure_methodology_explain_pos_bias_at_low_fcf_high_SWE.ipynb`

Targeted investigation of positive bias at low-forest-cover-fraction sites with high
SWE, focused on three problem stations (1222_UT, 314_WY, 626_UT). Writes
`figures/v9/supplemental_figure_methodology.png`/`.pdf` — a **different** figure from
Fig. A1 — plus per-station context maps and multi-year high-SWE-vs-moderate-SWE
time-series panels.

> Its opening markdown title is the same as `supplemental_figure_methodology.ipynb`
> and is misleading; the content is the low-FCF positive-bias investigation.

### `create_all_station_comparison_dataset.ipynb`

Builds the comparison NetCDFs in `comparison_datasets/` (Coiled, distributed over all
~969 stations): loads stations via `easysnowdata` and filters SWE series (negative
values, jump artifacts > 0.2 m, gaps > 10 days in any 20-day window); keeps snow years
with ≥ 0.05 m SWE for ≥ 55 days in any 60-day window; derives pillow onset as the last
day SWE ≥ 95 % of the water-year maximum; sweeps buffer radius × FCF threshold and
extracts the SAR onset; writes `(station, WY, buffer_radius, fcf)` NetCDFs. **Kept
because it is the only way to regenerate the input the two figure notebooks read.**

> It loads `config/global_config_v6.txt`, not v9/v10 — possibly frozen deliberately,
> possibly stale. (Until 2026-08-04 the path read `'../config/global_config_v6.txt'`,
> which `Config` resolved against the repo root and so pointed outside the repo; the
> cell had not been re-run since.)

## Paths and inputs

Figures go through one `FIGURE_DIR = Path('figures') / VERSION` constant (`VERSION` =
`config.version`), so v9 and v10 renders never collide. The six unscoped pre-versioning
PNGs that used to sit at the top level of `figures/` were deleted with the archive —
no live `savefig` reproduced any of them.

Comparison NetCDFs stay flat in `comparison_datasets/` rather than in per-version
subdirectories, because their filenames already carry the version and several vintages
coexist. **Only one is now live:**
`snotel_sar_differences_UPDATED_SNOTEL_LOCATIONS_andreq10cmSWEfor60days_v9.nc` (12 MB),
read by both figure notebooks. The other ~23 files (~690 MB, gitignored) are v1–v8
vintages plus the two large `spatial_*.nc` files that only the now-archived
`environmental_conditions_analysis.ipynb` used — deletable disk, not provenance.

There is **no local `config/` directory**: the notebooks' `Config('config/global_config_vN.txt')`
strings resolve against the repo root (`Config._resolve_repo_path()`), i.e. the shared
[`../../config/`](../../config/).
